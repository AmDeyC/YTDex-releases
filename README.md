# YTDex releases

This repository only hosts **YTDex installers and update files** for Windows 10/11 (x64).
The source code is kept elsewhere; nothing else lives here.

- **Install:** download `YTDex-<version>.Setup.exe` from the [latest release](https://github.com/amitavadc/YTDex-releases/releases/latest) and run it.
- **Updates:** installed copies of YTDex update themselves from this repository's latest release
  (`RELEASES` + `ytdex-<version>-full.nupkg`). Please don't delete or rename those files in a release.

YTDex is based on [YouTube Desktop](https://github.com/mikepruett3/youtube-desktop) by Mike Pruett (MIT).
